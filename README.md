# Hotel Listing App

A full-stack hotel management and listing platform where users can browse, add, edit, and delete hotel entries with image uploads, price-based filtering, and search.

## Features
- 🏨 CRUD operations for hotel listings (add, edit, delete)
- 🔍 Search hotels by name
- 💰 Filter by min/max price range
- 📄 Pagination for large hotel lists
- 🖼️ Image upload and preview support
- 🗺️ Google Maps integration for hotel location
- ⚡ Redux and Helmet Toolkit for state management
- 📱 Responsive card-based UI

## Tech Stack
**Frontend:** React, React Router, Redux Toolkit, Axios, React Helmet Async  
**Backend:** Node.js, Express, postgresql  
**Styling:** Custom CSS with CSS variables (design tokens)

## Getting Started
\`\`\`bash
# Clone the repo
git clone https://github.com/babu9342/Hotel-crud/

# Install dependencies (frontend & backend)
npm install

# Run backend
npm run dev

# Run frontend
npm start
\`\`\`
